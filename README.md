# Flask Portfolio Website

A simple personal portfolio web application built with Flask.  
It contains multiple pages (Home, Info, Skills, Contact) and demonstrates routing, templating, and form handling.

---

## 🚀 Features

- Multi-page Flask web application
- Dynamic rendering using Jinja2 templates
- Contact form with POST handling
- Flash messaging system
- Clean routing structure
- Beginner-friendly backend project

---

## 🧰 Tech Stack

- Python
- Flask
- HTML
- CSS
- Jinja2

---

## ⚙️ Installation & Setup

### 1. Clone the project
```bash
git clone https://github.com/your-username/flask-portfolio.git
cd flask-portfolio
```

### 2. Create virtual env 
``` 
   python -m venv venv
```
Activate it:

- Windows

```
venv\Scripts\activate
``` 
### 3. Install dependencies
```
pip install flask
```

### 4. Run the application
```
python app.py
```
### 5. Open in browser
```
http://127.0.0.1:5000/

```
